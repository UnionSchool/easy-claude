# easy-claude

[English](README.md) | **简体中文**

查看 Claude Code 订阅剩余额度，并在 Claude 桌面应用旁显示透明彩色圆环。第三方辅助工具，与 Anthropic 无官方隶属关系。

需要 Node.js 22+ 与 Claude Code 订阅登录；不支持把 API Key 账单余额当作订阅额度。

## 出口 IP 保护（应用代理）

“额度自动刷新”默认关闭，关闭时仅手动刷新；开启后每5分钟查询，重置或提醒到点后每分钟确认。手动刷新始终保留，自动和手动均遵守限流冷却。IP复查与时钟独立运行。

Claude App 与 Claude Code CLI 共用固定本机代理 **http://127.0.0.1:18197**。桌面使用官方 `egressProxyUrl` 配置，终端Code使用 `~/.claude/settings.json` 的代理环境变量。保持Dock、Spotlight及终端正常启动，不添加外层沙箱或修改官方程序。此前外层沙箱与Chromium自身沙箱冲突，桌面受保护启动方案已撤回。

在“更多设置”中填写IPv4白名单，再打开“出口 IP 保护”。只有本轮IP验证成功且匹配白名单才转发。easy-claude未运行、开关关闭、验证失败/过期/未知或IP不匹配时，代理拒绝新请求并关闭已有隧道。打开工具会启动代理，开关关闭时也保持阻断。“退出”前的“启动 Claude”仅在点击时正常打开官方应用。

修改代理后需要用户自行重新打开Claude，不自动重启。此方案是应用代理控制，不是系统防火墙：官方更新器、外部浏览器及忽略代理变量的程序不一定受控。当前代理只支持IPv4 HTTPS CONNECT 443，拒绝IPv6与其他目标端口；尚不能宣称所有Claude相关流量均受保护。

[安装、代理配置、关闭与卸载](docs/出口IP保护.md) · [开发验证记录](docs/版本/出口IP保护开发管理.md)

## 安装与使用

```sh
npm i -g easy-claude
easy-claude
easy-claude show
```

读取 Claude Code 登录账号，桌面端请使用同一账号。登录不存在或过期时，执行 `claude auth login` 后重试。仅安装 Claude 桌面端、没有 Claude Code 登录时不能查询。

## 圆环

- macOS 14+；跟随 Claude 桌面应用窗口，前台显示，后台隐藏。默认左下角账户栏右侧，32×32，透明背景，无底板和阴影。
- 显示剩余百分比：大于 50% 为绿色、20%–50% 橙色、低于 20% 红色；未知或过期为灰色，不伪装满额。
- 按返回的真实额度自适应：只有周额度时显示单周环和周剩余数字，不显示5小时项；只有5小时则显示单5小时环，两项都有时双环同时显示：周额度为外侧粗实线环，5 小时额度为内侧细实线环（外环未使用部分为淡色虚线底轨），中心数字默认显示 5 小时剩余百分比（环内省略 %，菜单保留），可在菜单点击“5小时”或“周”切换并记住选择；两环独立配色和判断过期。右键查看“5小时 · 剩余百分比 · 重置时间”和“周 · 剩余百分比 · 重置时间”（重置使用电脑本地时区）、刷新、恢复位置或退出，双击刷新，拖动校准。
- 开启额度自动刷新后每5分钟查询，关闭后仅手动刷新；冷却期间暂停请求；超过有效期或已到重置时间的数据标为过期；接口错误会立即标记未知。
- 不显示“7天”等底部文字，详情在悬停提示和菜单。状态栏显示产品图标和剩余额度或恢复倒计时。
- 基于窗口边界定位，不识别头像，不读取桌面聊天或截图；无法自动核对桌面账号与 CLI 账号一致。

## 电子时钟

运行 `easy-claude show` 时同时显示透明电子时钟，跟随 Claude 前台窗口，后台隐藏；可独立拖动位置。默认与额度环并排放在左下角，额度环在左、时钟在右；已有拖动位置继续保留，可从菜单选择“恢复默认位置”应用新布局。

默认硅谷 `America/Los_Angeles`，跟随系统12/24小时制，仅显示时分；自动按目标时区处理夏令时，与电脑系统时区无关。右键时钟、圆环或状态栏图标，使用城市时间子菜单按顺序选择硅谷、洛杉矶、西雅图、华盛顿、哥伦布、新加坡、上海，或输入其他 IANA 时区名称。时区、位置和显示开关自动保留；“恢复默认位置”同时重置圆环与时钟的位置。数字颜色按所选时区切换：09:00–18:00 绿色，18:00–24:00 橙色，00:00–09:00 红色。边界 09:00 起为绿、18:00 起为橙、午夜转红。时钟使用本机系统时间，无需登录或网络校时，不修改系统时区。

华盛顿指美国华盛顿特区，哥伦布指俄亥俄州哥伦布，二者使用 `America/New_York`；硅谷、洛杉矶和西雅图使用 `America/Los_Angeles`。城市名称独立保存，相同时区也可分别选择并显示。

## 数据与认证边界

使用本机 Claude Code 中存在的 `https://api.anthropic.com/api/oauth/usage` 接口，仅发送只读 GET，不创建模型请求或刷新/修改凭据。它不是公开稳定 API，可能因服务调整失效。

macOS 优先读取 `Claude Code-credentials` 钥匙串项；其他情况读取 Claude Code 的 `.credentials.json`。设置 `CLAUDE_CONFIG_DIR` 时只读取该目录的凭据文件，不猜测自定义钥匙串名称。可能需要系统允许访问已有钥匙串项。

登录令牌只在内存中用于固定官方源；禁止跟随重定向，不输出原始错误正文或令牌。查询总超时 15 秒，遇到 429 提示稍后重试。macOS 优先使用 HTTPS_PROXY/ALL_PROXY 环境变量，否则读取已启用的系统 HTTPS 代理；经系统 curl 校验 TLS，凭据仅经标准输入传入，不出现在命令参数中，不修改系统代理。未配置代理时直连。HTTP 403 提示服务拒绝访问，与 401 登录失效区分。OAuth 权限可能不足；如重新登录仍无法查询，应停止请求并检查接口兼容性。

展示服务端 `utilization` 的剩余值 `100 - utilization`。各窗口独立，额外付费额度不混入百分比。未知字段不硬编码为零。此接口读取的是订阅窗口，不是当前聊天上下文剩余量。

## 开发

```sh
npm test
npm run build:overlay
```

构建需要 Swift 6 与 Xcode Command Line Tools，生成 Intel/Apple Silicon 通用应用；使用 ad-hoc 签名，未开发者签名或公证。测试使用模拟响应，不发送模型请求。

## 发布

升级 package.json 版本，提交后推送同版本 v 标签，由 GitHub Actions 自动测试、构建通用浮窗并发布 npm。稳定版使用 latest，预发布使用 next。发布任务使用 npm Environment，仓库 Deployments 可查看记录。

发布使用 Easy 系列共用的 NPM_TOKEN Secret；每次发布前检查有效期和包权限。首次配置后，普通代码推送只运行 CI，版本标签才发布 npm。


浮窗使用 `easy-claude show` 启动；原 `overlay` 命令保留兼容。

周倒计时只显示最大单位，例如“6天后 25日 06:17 重置”，不足一天按小时、不足一小时按分钟。5小时窗口保留时分组合，例如“3小时2分后 07:59 重置”，没有小时则“22分后 07:59 重置”，省略为零的单位。绝对重置时刻使用电脑本地时区；周含日，5小时不含日期。


命令更新：`easy-claude update`，成功后会自动退出旧浮窗并打开新版。旧版本尚未提供 update 时，可先执行 `npm i -g easy-claude@latest`。更新过程中需要正常网络及原安装目录写入权限，不会自动使用 sudo。

## 额度可用提醒

在状态栏图标 或浮窗右键菜单开启“额度可用提醒”。首次开启需允许系统通知。仅在额度耗尽且重置时间有效时启用；当前已可用或数据未知时提示刷新后重试。

只有5小时或只有周额度时等待对应恢复；两项都耗尽时等待较晚时间，仍有剩余的窗口不参与等待。到点后按额度自动刷新开关自动或手动确认，所有已知窗口均有剩余，才发送一次系统通知和提示音，然后自动关闭开关。若等待期间再次耗尽，会继续等到有效恢复。

开启状态跨更新/重启保存；关闭可取消。提醒遵循额度自动刷新开关；关闭时需手动刷新确认，失败时保留提醒。工具完全退出期间不能提醒，重启后遵循原额度自动刷新开关；系统通知权限、专注模式和声音设置可能影响通知展示或声音。不调用模型、不消耗对话额度。

## 公网IP与城市

菜单显示“城市名称·IP地址”，仅请求一次 `https://ipinfo.io/json`，同时获取当前请求出口的IP、城市和时区；城市名称按接口返回显示。启动和每5分钟刷新，点击该菜单项可立即重查。IP取不到显示“IP异常”；城市取不到显示“城市未知”。

查询遵循已有HTTPS/ALL代理环境或macOS系统HTTPS代理。这里显示查询服务看到的网络出口；Clash分流时可能与AI请求不同，城市不代表电脑所在地，关闭“跟随IP时区”时不改变时钟时区。不主动保存IP历史，不发送账号凭据。


IP地理库的城市与时区可能存在偏差或互相不一致；显示接口返回值，仅校验时区名称有效性，不根据城市猜测时区。

## 跟随IP时区

菜单开启“跟随IP时区:ipinfo.io”后，时钟按地理接口返回的IANA时区显示当地时间，自动处理夏令时，继续跟随系统12/24小时制；时钟下方显示IP返回的城市名称，宽度不超过时间文字，手动时区选择隐藏。地理信息每5分钟刷新；关闭保护时点击IP菜单也可刷新。保护开启时该菜单触发保护重新检测，地址同步更新，地理信息仍独立查询。

关闭后恢复之前手动选择的城市和时区，并重新显示选择菜单。取不到IP或有效时区时，时钟回退到手动设置的时区，菜单提示“IP时区不可用，显示自定义时间”；开关仍开启，获取成功后继续跟随。开关和手动设置跨重启/更新保存，不保存IP历史。IP地理数据可能不准确，跟随的是出口时区，不修改电脑系统时区。

## 开机启动与12小时时段

从菜单勾选“开机启动”后，在登录当前macOS用户时自动运行本工具的 `show`，默认关闭，不会自动登录系统或打开官方Codex/Claude应用。关闭仅取消下次登录启动，当前浮窗继续运行。系统若禁止此后台项目，则需在系统设置中允许。

登录配置保存当前Node/npm安装路径，常规原前缀npm更新可继续使用；删除或迁移Node/npm目录后，从新安装打开浮窗并关闭再开启此选项以更新路径。

12小时制时段按时钟所选时区计算；跟随IP时使用有效IP时区，获取失败沿用自定义时间。浮窗、城市菜单和辅助文本使用相同五时段，Claude时间在前、时段在右；Codex时段在时间上方。零点如“凌晨 00:12”、正午如“下午 12:12”；24小时制不增加时段文字，额度重置时刻继续使用系统格式。

## 状态栏与控制面板

左键点击状态栏图标打开面板，每次打开默认收起。收起只显示额度、当前时间、出口IP以及“更多设置／退出”；点击“更多设置”原位展开全部设置。右键图标或浮窗仍可使用原菜单。

有有效额度时显示中心额度的剩余百分比（Claude优先5小时、缺失时用周；Codex只有周时显示周）；点击面板额度行或兼容菜单可切换中心额度。任何已知总额度耗尽时，状态栏显示耗尽窗口中较晚的恢复倒计时。到点显示“确认中”，需重新查询确认后才切回百分比。未知、过期、缺失恢复时刻或查询失败不伪装为0%、满额或恢复可用。

未登录显示登录指引；点击复制只写入登录命令到剪贴板，不自动打开终端或运行命令。登录过期、查询失败分别显示，不会因为错误文字含“检查登录”就判为未登录。登录应与官方桌面使用同一账号；本工具无法替用户证明两边账号一致。时间、IP与设置不依赖订阅登录。

操作面板采用原生AppKit/SwiftUI，额度查询不调用模型，不新增Node第三方依赖。状态栏持续更新本地显示，额度按自动刷新开关或手动查询；浮窗仍仅跟随官方应用前台窗口显示。开机启动、提醒和自动更新的原设置继续保留。

## 中英文界面

默认跟随系统首选语言，中文系统显示简体中文，其余语言显示英文。展开“更多设置”后选择“语言”：跟随系统／简体中文／English；右键兼容菜单也可切换。手动选择即时生效，跨重启保留，不改变电脑语言、时区或12/24小时制。CLI沿用本工具保存的语言，也可临时设置 `EASY_LANGUAGE=en` 或 `EASY_LANGUAGE=zh`。

收起面板中，网络出口文字下方至底部分隔线的空白由约48pt减至约24pt，不改变网络刷新频率或控件操作。

- 时间浮窗：12小时制显示“10:09 上午”，时间在前，时段在右且字号为数字的一半；城市在下方。英文为“10:09 AM”，24小时制不显示时段。Claude适用；Codex时段放在时间上方，保持各自浮窗边界。

额度自动刷新默认关闭，开启后每5分钟查询，重置/提醒到点每分钟确认，关闭后仅手动。服务返回429后先等待10分钟、后最长15分钟，手动刷新遵守冷却，成功后清零。网络与保护合为一个分区，保护开启时当前出口与保护检测同步更新；失败显示未知，白名单和复查周期在更多设置中修改。关闭保护时IP/城市查询每5分钟刷新。
