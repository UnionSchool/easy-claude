# IP 查询限流修复（未发布）

## 行为

- 保持ipinfo主查，失败、超时、非法响应或429时，仅尝试一次`https://api.ipify.org?format=json`备用。备用仅提供IP；城市/时区未知时回退原手动时区，不继承旧地理信息。
- 每轮保护检测至少60秒，复查选项60/120/300秒；旧30秒偏好在启动迁移。手动重查、网络变化、唤醒、配置修改不能绕过最小间隔；撤销立即生效，排队期间保持阻断，到点执行最新检测。
- 保护服务各源429冷却10分钟；主源冷却时直接用备用，双源都不可用则阻断。双源各5秒，总检测仍受13秒边界约束，不关闭TLS校验、不跟随重定向。
- 主源返回合法但不在白名单的IP时直接阻断，不尝试用备用挑选一个可放通的IP；旧请求取消时不能继续备用或更新检测时间。
- 地理查询正常300秒，手动/网络事件触发也至少60秒。ipify备用不提供地理字段，`跟随IP时区:ipinfo.io`标签保持不变。
- 跨检测源可能存在分流差异，单次IP查询仍只证明对应检测连接出口，不扩大保护保证范围。官方接口格式依据[ipify官方接口文档](https://www.ipify.org/)。
