# 1.0.1 版本开发管理

## 版本结论

- 目标版本：easy-codex 与 easy-claude 统一 1.0.1。
- 当前阶段：本机开发完成、发布预检中；尚未发布，不把效果图当作实际运行结果。
- 沿用现有查询、时钟、提醒、登录启动及更新链路；不修改官方应用。
- 用户已授权开发、测试后由 GitHub 自动发布 npm。
- 本地未发布的 Agent 协作入口不属于本版，不混入提交和 npm 包。

| 区域 | 本版行为 | 验收重点 |

Codex 当前真实返回只有周额度时仅显示周；若以后提供5小时窗口则自适应。Claude优先显示5小时，没有时显示周。状态栏遵循已有中心额度选择；任一已知总额度耗尽均显示恢复倒计时，多个耗尽窗口取较晚重置时刻。重置时刻到达后必须重新确认，不能直接宣称可用；缺失/过期/查询失败显示未知，不回退旧数字。

## 界面与设置约定

点击状态栏打开原生弹出面板。默认收起；更多设置在原面板展开，屏幕高度不足时可滚动。右键兼容原菜单。时间和网络在没有登录时仍可用。手动时区仅在关闭跟随IP时显示；获取IP时区失败仍沿用已保存的自定义时间。

只有用户主动操作才改设置。升级保留位置、时区、中心额度、提醒、自动更新和登录启动；不替用户启用任何开关。复制登录命令只写入剪贴板，不自动运行，不索取Token。

## 技术改动与边界

- 查询层传递明确认证状态，不能按“请检查登录”这类通用错误文字猜测。
- Codex仍通过官方App Server，Claude仍只读订阅凭据和官方额度接口，不调用模型。
- 图标用本地矢量模板绘制，不依赖远程图标或新增Node依赖。
- 发布包携带双架构原生应用；操作面板复用已有动作，不另造更新/认证系统。

## 发布管理

版本、v标签和Release必须一致为1.0.1。README只保留本版更新说明，历史保留CHANGELOG。只暂存本版文件；检查包内容不含Agent、本地记忆和凭据。核实共用NPM_TOKEN记录期限与本次发布权限，不读取或记录值。Actions成功后还需核实公开registry版本、dist-tags、实际安装、Deployment成功及Release。

## 回退与已知边界

回退可安装上一正式版本并show重开，保留UserDefaults；不移动已推送标签。图标为辅助工具标识，不表示官方出品。额度受服务端返回与网络影响；实际通知弹出、真实注销重启和跨机器多屏验收应单独标注，不能由编译成功代替。

## 开发问题与处理

- Claude原额度选择标识与Codex不同，真实设置动作测试发现周额度选择未生效；按原产品标识对接后测试通过，没有统一改写原协议。
- 原生macOS进度控件未按预期着色，替换为轻量矢量进度条；开关右对齐，展开高度与屏幕适配，已检查实际绘制。
- 测试宿主的SwiftUI辅助功能子树未提供可用按钮节点，改用向自身测试窗口派发真实鼠标事件；仍断言更多设置展开与收起成功，未跳过交互测试。
- Codex真实账号查询成功并返回单周窗口；本机Claude凭据已过期，验证过期提示，正常额度态通过隔离响应覆盖。没有清理或刷新用户凭据。
- 新增测试在独立Bundle偏好域运行，不开启实际提醒、自动更新或登录项，不访问模型；生成的界面截图在native/build/control-previews，不进入npm包，可通过npm run test:controls重现。
