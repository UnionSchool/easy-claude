# easy-claude 1.3.4 开发与发布

- 时间：2026-11-26，America/New_York；工具：Antigravity。
- 用户授权优化额度检查以降低 429 限流并发布 1.3.4；不启动或关闭官方 Claude，不修改代理配置，不擅自替换本机全局安装。

## 内容

- 额度自动刷新改为前台/面板按需驱动：仅在 Claude 处于前台、点开控制面板、首次无快照或开启的“额度可用提醒”到点时自动查询，后台空闲不再空转。
- 正常自动周期放宽为 10 分钟（600 秒），重置或提醒到点确认放宽为 3 分钟（180 秒），快照过期阈值同步调整为 20 分钟（1200 秒）。
- 遇到登录失效（`auth_required` / `auth_expired`）时暂停自动轮询，等待重新登录后手动“重新检测”；HTTP 429 响应支持读取服务端 `Retry-After` 秒数作为冷却下限（与既有 10/15 分钟退避取较大值）。
- 额度查询与出口 IP 保护联动：开启出口 IP 保护且未放通时暂停额度查询（绝不直连 `api.anthropic.com`），放通后通过 `http://127.0.0.1:18197` 代理发出。
