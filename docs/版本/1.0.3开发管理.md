# 1.0.3 版本开发管理

## 当前阶段

2026-10-22（America/Los_Angeles，Codex）：用户授权两工具测试后一起发布，目标1.0.3。1.0.3已完成GitHub/npm发布及公开、本机正式安装验收。

## 本版功能

- 正常额度每5分钟刷新；到重置时刻或提醒到点后，仍每分钟在线确认。
- 展示数据有效期为10分钟，避免正常刷新间隔内提前显示未知；查询错误和过期窗口仍明确标记。
- 遇到429先暂停10分钟，随后最长15分钟；成功后恢复正常频率，手动和提醒查询共用冷却。
- 浮窗保持时段在时间右侧、字号减半，城市在下方。
- 隔离测试验证后台额度刷新期间的连续输入及组字保持，不主动激活官方应用。

IP仍每5分钟独立查询，已有语言、时区、位置、自动更新、提醒及开机启动配置保留。额度来源、认证和查询协议不变，不修改官方应用，不调用模型。正常每300秒；到重置或提醒时刻每60秒确认；Codex展示TTL600秒，提醒确认的新鲜度120秒仍严格。Claude429冷却10/15分钟封顶，退出重开不延续内存冷却。
