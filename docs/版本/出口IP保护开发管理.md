## 启用与关闭

在开发版面板展开“更多设置”，输入允许的 IPv4（英文/中文逗号、空格或换行分隔），再打开“出口 IP 保护”。开关、白名单和30/60/120/300秒复查间隔由本工具偏好保存，默认关闭。编辑白名单时立即阻断，等待新配置验证，旧查询不能恢复放行。

显示“代理已放通”后，桌面可以点击底部“启动 Claude App”。如果桌面正在运行，会明确提示用户自行退出；不主动结束现有会话。安装位置通过系统应用查询发现，启动器使用该应用内的 Claude 可执行文件。

终端入口：

```sh
easy-claude protected
easy-claude protected --help
```

开发源码可用 `node bin/easy-claude.js protected`，正式 npm 1.0.3 尚不包含本功能。后续参数直接传给 Claude Code，不经 shell；本轮测试不执行上述真实启动命令。

关闭开关会撤销 IP 限制、断开旧隧道，已有受保护程序下次重连可经原代理正常转发。macOS 沙箱无法从已启动进程中移除，因此关闭时保留本机代理供这些程序继续使用；不是自动改为直接联网。

退出 easy-claude 会关闭代理并切断受保护连接。重新打开后代理端口改变，已有受保护程序需要自行退出并从新入口启动。卸载前先关闭保护并结束受保护会话，再使用普通 Claude 启动方式；没有系统代理、防火墙或登录配置需要回退。本轮未新增独立安装组件或执行卸载。

## 控制与故障行为

| 场景 | 行为 |
| --- | --- |
| 初次启用、重启、网络变化、唤醒 | 先阻断再检测 |
| 定期复查 | 旧租约尚有效时继续连接；成功续租，失败撤销 |
| 旧检测晚返回 | 检测代次不匹配，不能放行 |
| 白名单编辑 | 立即暂停转发，编辑完成后验证新配置 |
| 验证过期 | 定时撤销，并在每批转发数据前检查单调时钟租约 |
| 控制程序退出或15秒无心跳 | 关闭服务与所有连接 |
| 服务崩溃、沙箱不可用 | 显示故障，不回退直连 |
| 用户关闭保护 | 关闭旧连接，允许无 IP 限制重连转发 |

本机代理只监听随机的 `127.0.0.1` 端口。服务发现采用本用户临时目录下0700目录内的0600 Unix socket，检查所有者和文件类型，拒绝覆盖活动服务。不读取、修改或转发 Claude 账号凭据。

保护服务检测固定 HTTPS IPinfo 地址，证书校验开启，12秒总超时、8KiB响应上限，不跟随重定向；强制 IPv4。只比较严格规范化的 IP，不把城市或时区当作授权依据。查询失败、非法响应、非白名单或返回地址族不符均阻断。429 后冷却10分钟，手动重新检测不能绕过冷却。

## 保证范围与待验收

- 只控制通过受保护入口启动的进程。现有普通 Claude 实例、其他入口启动的程序不自动受控；界面明确显示适用范围，不能据开关亮起认定全部 Claude 已受保护。
- 当前仅支持 IPv4 的 HTTPS CONNECT 443，拒绝其他端口与普通 HTTP，IPv6 不转发。Code 的本地服务、浏览器认证、工具子进程等可能需要额外的受控网络能力，未验收前不能承诺正常。
- 已验证直接 TCP/UDP 与普通子进程继承；LaunchServices、XPC 和系统代发网络尚未证明无法绕过。`sandbox-exec` 已弃用，系统版本兼容性仍需验收。
- 网络路径通知由 NWPathMonitor、唤醒通知接入，但没有实际断网、切换网络或休眠测试。通知存在时序窗口，同一本地网关不证明各目标使用同一公网出口，IP查询只证明该次检测连接。
- 周期查询在上次有效租约内保留连接，不能保证未通知的出口变化发生瞬间就阻断。界面退出、服务崩溃和停止转发已有本机测试；更多异常及缓存已入内核的数据无法据此承诺零时序窗口。
- 真实 Claude 和辅助进程测试仍等待用户明确确认，不自动继续。正式发布须完整验收后另行授权。
