# 1.2.0 开发与发布管理

## 内容与边界

- 最低IP复查60秒（手动/网络/配置触发同样限流），旧30秒偏好迁移；等待期间保持阻断，旧查询不能更新时间或恢复放行。
- ipinfo主查，失败/限流使用ipify；主源合法但不在白名单直接阻断，不挑选更有利的备用结果。备用只有IP，不伪造城市/时区。
- 绿色启动Claude代理、黄色停止Claude代理。首次启动保存原字段，停止按字段恢复并保留用户后续其他修改；旧版缺少原记录时明确确认默认恢复。机器级策略、坏JSON、不安全权限/链接或并发变化拒绝覆盖。
- 安装/更新/启动仅status只读，管理员写入由用户点击发起；不自动启动/关闭Claude。代理变更需用户手动重开Claude。没有系统过滤扩展，不承诺所有流量或所有目标出口相同。

## 已验证与待验证

- 开发工作区48项Node测试（包含原Agent1项）；清洁发布候选应为47项，代理/网络隔离18项。16种中英文/开关/展开/代理状态离屏检查、调度、429、锁与双架构自检已通过。
- 代理配置6项测试在临时目录运行同一系统工具脚本，仅把root UID断言替换为测试UID；覆盖备份还原、空配置、取消授权、机器策略、坏JSON、并发、后加字段、旧版默认恢复和篡改。
- ipify独立HTTPS证书/JSON/IPv4检查通过。AppleScript参数传递与管理员语法编译通过，没有执行真实管理员修改；不能把模拟/临时目录结果等同真实授权验收。
- 当前用户已有代理配置的只读检查与本机开发版升级已验证。真实管理员授权/停止恢复、Claude重开后的业务与网络切换/唤醒仍待手动验收，发布说明保留此限制。
