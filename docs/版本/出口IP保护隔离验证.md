- 前两步验证通过：独立状态机测试，以及 Mac 上使用测试程序的真实 TCP、TLS、IPv6 和沙箱验证。

## 本轮改动

| 文件 | 用途 |
| --- | --- |
| `scripts/ip-guard-proof/guard.mjs` | 严格 IP 解析、HTTPS 检测、代次、单调时钟租约、失败阻断与限流 |
| `scripts/ip-guard-proof/gateway.mjs` | 仅接收夹具目标的本地 CONNECT 样机，撤销放行时关闭两端连接 |
| `scripts/ip-guard-proof/verify.mjs` | 独立逻辑测试和本机网络验收 |

没有修改正式 `src/`、原生源码、包配置或原有测试。本轮新增脚本未接入正式命令，不随现有 npm files 清单交付。无新依赖、签名或系统扩展；本轮没有原生代码改动，因此不重建或启动浮窗，不执行会激活输入窗口的焦点/UI 测试。

## 待验证和未实现

- Claude Code、Claude 桌面、必要辅助进程、登录、真实流式生成和真实账号均未测试；未启动、退出、暂停或重新配置正在使用的 Claude。
- 网络变化、唤醒、监控服务重启和通信中断在第一步通过撤销事件注入验证；尚未接入实际系统通知或独立监控服务 IPC。未断网、切 Wi-Fi、休眠或重启电脑。
- 强退的是独立样机网关。单独监控服务失联后的真实 IPC 行为、事件循环卡死与网关恢复，尚未实现/验收，不能由一次强退测试概括成全部故障可靠。
- 沙箱只验证直接 TCP/UDP 及普通子进程继承，尚未验证 LaunchServices、XPC、系统代发请求或桌面多进程的完整防绕过。`sandbox-exec` 已弃用，长期兼容性待评估。
- 样机按连接到的目标地址族与验证族比对，拒绝 IPv4 映射 IPv6；正式双栈解析、DNS、每地址族独立检测与路由一致性尚未实现。
- 独立样机不提供通用代理、产品 UI、配置持久化、定期复查服务、启动器和安装/卸载流程。关闭样机后代理端口停止可用，不自动替用户配置直连。
- 真实网络事件与未通知的出口变化存在检测窗口；同一本地网关不证明所有目标使用同一个公网出口。查询只证明该次检测连接。
- 没有实测公开 IP 服务、真实 429、其他 macOS 版本或真实 Claude；没有正式发布、更新正式包或系统网络配置。

## 复现与清理

在仓库根目录执行（macOS，需要允许监听本机端口和启动独立沙箱）：

```sh
node --test --test-timeout=15000 scripts/ip-guard-proof/verify.mjs
npm test
git diff --check
```

脚本只监听 `127.0.0.1` / `::1` 随机端口，使用测试服务器、临时证书和独立 Node 子进程。公网格式探针仅尝试文档保留地址，期望在沙箱中立即得到 EPERM，不访问 Claude 或 IPinfo。所有 socket、计时器、子进程及临时目录在测试结束清理。

受限执行环境首次运行会因禁止本地监听或嵌套沙箱而返回 EPERM；本次在获准的隔离测试执行环境复跑通过，没有跳过沙箱断言或降低验证要求。

后续只有获得用户明确确认，才进入真实 Claude 测试阶段。
