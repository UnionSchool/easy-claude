# easy-claude

查看 Claude Code 订阅剩余额度，并在 Claude 桌面应用旁显示透明彩色圆环。第三方辅助工具，与 Anthropic 无官方隶属关系。

需要 Node.js 22+ 与 Claude Code 订阅登录；不支持把 API Key 账单余额当作订阅额度。

## v0.2.3 新增与调整

- **命令更新**：新增 `easy-claude update`，从官方 npm 更新当前全局安装。
- **自动重开**：`easy-claude show` 会先退出自身旧浮窗，再打开新版；设置保持不变。

- 统一时间颜色：所选城市当地时间 **00:00–09:00 红色、09:00–18:00 绿色、18:00–24:00 橙色**，绿色时段延长到18:00。
- 09:00转绿、18:00转橙、午夜转红，自动适应目标时区夏令时。
- 保留已有时区、城市、位置和显示选择；额度圆环颜色阈值保持原有规则。

完整版本说明见 [CHANGELOG](CHANGELOG.md)。

## 安装与使用

```sh
npm i -g easy-claude
easy-claude
easy-claude show
```

读取 Claude Code 登录账号，桌面端请使用同一账号。登录不存在或过期时，执行 `claude auth login` 后重试。仅安装 Claude 桌面端、没有 Claude Code 登录时不能查询。

## 圆环

- macOS 14+；跟随 Claude 桌面应用窗口，前台显示，后台隐藏。默认左下角账户栏右侧，32×32，透明背景，无底板和阴影。
- 显示剩余百分比：大于 50% 为绿色、20%–50% 橙色、低于 20% 红色；未知或过期为灰色，不伪装满额。
- 按返回的真实额度自适应：只有周额度时显示单周环和周剩余数字，不显示5小时项；只有5小时则显示单5小时环，两项都有时双环同时显示：周额度为外侧粗实线环，5 小时额度为内侧细实线环（外环未使用部分为淡色虚线底轨），中心数字默认显示 5 小时剩余百分比（环内省略 %，菜单保留），可在菜单点击“5小时”或“周”切换并记住选择；两环独立配色和判断过期。右键查看“5小时 · 剩余百分比 · 重置时间”和“周 · 剩余百分比 · 重置时间”（重置使用电脑本地时区）、刷新、恢复位置或退出，双击刷新，拖动校准。
- 可见时每 5 分钟查询，10 分钟前的快照或已到重置时间的数据标为过期；接口错误会立即标记未知。
- 不显示“7天”等底部文字，详情在悬停提示和菜单。菜单栏标记为 EA。
- 基于窗口边界定位，不识别头像，不读取桌面聊天或截图；无法自动核对桌面账号与 CLI 账号一致。

## 电子时钟

运行 `easy-claude show` 时同时显示透明电子时钟，跟随 Claude 前台窗口，后台隐藏；可独立拖动位置。默认与额度环并排放在左下角，额度环在左、时钟在右；已有拖动位置继续保留，可从菜单选择“恢复默认位置”应用新布局。

默认硅谷 `America/Los_Angeles`，24 小时制，仅显示时分；自动按目标时区处理夏令时，与电脑系统时区无关。右键时钟、圆环或菜单栏 EA，使用城市时间子菜单按顺序选择硅谷、洛杉矶、西雅图、华盛顿、哥伦布、新加坡、上海，或输入其他 IANA 时区名称。时区、位置和显示开关自动保留；“恢复默认位置”同时重置圆环与时钟的位置。数字颜色按所选时区切换：09:00–18:00 绿色，18:00–24:00 橙色，00:00–09:00 红色。边界 09:00 起为绿、18:00 起为橙、午夜转红。时钟使用本机系统时间，无需登录或网络校时，不修改系统时区。

华盛顿指美国华盛顿特区，哥伦布指俄亥俄州哥伦布，二者使用 `America/New_York`；硅谷、洛杉矶和西雅图使用 `America/Los_Angeles`。城市名称独立保存，相同时区也可分别选择并显示。

## 数据与认证边界

使用本机 Claude Code 中存在的 `https://api.anthropic.com/api/oauth/usage` 接口，仅发送只读 GET，不创建模型请求或刷新/修改凭据。它不是公开稳定 API，可能因服务调整失效。

macOS 优先读取 `Claude Code-credentials` 钥匙串项；其他情况读取 Claude Code 的 `.credentials.json`。设置 `CLAUDE_CONFIG_DIR` 时只读取该目录的凭据文件，不猜测自定义钥匙串名称。可能需要系统允许访问已有钥匙串项。

登录令牌只在内存中用于固定官方源；禁止跟随重定向，不输出原始错误正文或令牌。查询总超时 15 秒，遇到 429 提示稍后重试。macOS 优先使用 HTTPS_PROXY/ALL_PROXY 环境变量，否则读取已启用的系统 HTTPS 代理；经系统 curl 校验 TLS，凭据仅经标准输入传入，不出现在命令参数中，不修改系统代理。未配置代理时直连。HTTP 403 提示服务拒绝访问，与 401 登录失效区分。OAuth 权限可能不足；如重新登录仍无法查询，应停止请求并检查接口兼容性。

展示服务端 `utilization` 的剩余值 `100 - utilization`。各窗口独立，额外付费额度不混入百分比。未知字段不硬编码为零。此接口读取的是订阅窗口，不是当前聊天上下文剩余量。

## 开发

```sh
npm test
npm run build:overlay
```

构建需要 Swift 6 与 Xcode Command Line Tools，生成 Intel/Apple Silicon 通用应用；使用 ad-hoc 签名，未开发者签名或公证。测试使用模拟响应，不发送模型请求。

## 发布

升级 package.json 版本，提交后推送同版本 v 标签，由 GitHub Actions 自动测试、构建通用浮窗并发布 npm。稳定版使用 latest，预发布使用 next。发布任务使用 npm Environment，仓库 Deployments 可查看记录。

发布使用 Easy 系列共用的 NPM_TOKEN Secret；每次发布前检查有效期和包权限。首次配置后，普通代码推送只运行 CI，版本标签才发布 npm。


浮窗使用 `easy-claude show` 启动；原 `overlay` 命令保留兼容。

周倒计时只显示最大单位，例如“6天后 25日 06:17 重置”，不足一天按小时、不足一小时按分钟。5小时窗口保留时分组合，例如“3小时2分后 07:59 重置”，没有小时则“22分后 07:59 重置”，省略为零的单位。绝对重置时刻使用电脑本地时区；周含日，5小时不含日期。


命令更新：`easy-claude update`，更新完成后运行 `easy-claude show`，会自动退出旧浮窗并打开新版。旧版本尚未提供 update 时，可先执行 `npm i -g easy-claude@latest`。更新过程中需要正常网络及原安装目录写入权限，不会自动使用 sudo。
